# TCRIA portal

A single static page that gives TCRIA a stable HTTPS entry point:
<https://wanglabcsu.github.io/TCRIA-portal/>

The page links to the live browser at <http://biotree.top:38123/tcria/>.

## Deploy

Settings → Pages → Source: `Deploy from a branch` → Branch `main`, folder `/ (root)`.

No build step, no dependencies: `index.html`, `favicon.svg`, `.nojekyll`.
